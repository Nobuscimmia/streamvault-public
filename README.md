# 🟠 StreamVault

**Automatic live stream recorder for cam sites — Windows**

StreamVault automatically records your favorite models on Chaturbate, Stripchat, BongaCams and Cam4. Set up AutoRecord, go to sleep, find everything saved when you wake up.

> 🇮🇹 [Leggi in Italiano](#-streamvault-italiano)

---

## ✨ Features

- **AutoRecord** — detects when a model goes online and starts recording automatically
- **Multi-site** — Chaturbate, Stripchat, BongaCams, Cam4
- **Video Editor** — trim, merge, generate GIFs, extract audio, contact sheet
- **Web Dashboard** — control recordings from your phone or tablet
- **Telegram Bot** — push notifications when a model goes online
- **Statistics** — charts, heatmaps, contribution graph, personal records
- **Auto Backup** — SFTP upload, CSV export, PDF report
- **Clipboard Monitor** — detects cam URLs you copy and offers to record instantly
