# 🟠 StreamVault

**Recorder automatico per live stream cam — Windows**

StreamVault registra automaticamente le tue modelle preferite su Chaturbate, Stripchat, BongaCams e Cam4. Avvia l'AutoRecord, vai a dormire, trovi tutto salvato.

---

## ✨ Funzionalità

- **AutoRecord** — rileva quando una modella va online e inizia a registrare automaticamente
- **Multi-sito** — Chaturbate, Stripchat, BongaCams, Cam4
- **Editor video** — taglia, unisci, genera GIF, estrai audio, contact sheet
- **Dashboard web** — controlla le registrazioni da telefono o tablet
- **Bot Telegram** — notifiche push quando una modella va online
- **Statistiche** — grafici, heatmap, contribution graph, record personali
- **Backup automatico** — upload SFTP, export CSV, PDF report
